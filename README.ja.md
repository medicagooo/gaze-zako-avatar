## プロジェクトについて

**gaze zako avatar** は、ステッカーを組み合わせてアバターを作る軽量な Web アプリです。髪型、肌、目、耳、髪飾り、顔アクセサリー、口、背景を選び、顔がひょっこりのぞくかわいいアイコンを作成できます。プレビュー、履歴への保存、ダウンロードに対応しています。

HTML、CSS、JavaScript、SVG で構成され、描画と画像の書き出しはすべてブラウザー内で行います。アカウント、バックエンド、データベース、AI API は不要です。淡いピンクと丸みのある UI はスマートフォンとパソコンに対応し、簡体字中国語・英語・日本語で利用できます。

## 主な機能

- **19 種類の編集可能なプリセット**：氷晶、月メイド、紫猫リボン、茶髪セージアイ、青花ボンネット、白桜リボン、金髪の晶霊、紅白夜桜、ミント水兵など。選択後も各パーツを変更できます。
- **豊富な素材**：髪型 15 種類、耳 8 種類、髪飾り 29 種類、顔アクセサリー 12 種類、口 11 種類、瞳の形 11 種類。該当する項目では「なし」も数に含みます。
- **自由な配色**：髪、肌、目、アクセサリーの色を変更でき、オッドアイにも対応。7 色の肌はアバターのサムネイルで表示され、眼帯は左右を切り替えられます。
- **10 種類の背景**：黒、白、透明、ティファニーブルーの水玉、ピンクの水玉、トランスジェンダーフラッグ、ピンク、ブルー、霧の青、夜桜と鳥居。
- **リアルタイムプレビューと書き出し**：単独で使える SVG、または 512 / 1024 / 2048 ピクセルの PNG。透明画像にプレビュー用の市松模様は入りません。
- **ローカル履歴**：作成ボタンで組み合わせを保存し、再編集、再ダウンロード、削除ができます。全削除には確認が必要です。同じ組み合わせの重複保存を防ぎます。
- **共有メニュー**：WeChat、QQ、X（Twitter）、WhatsApp、Telegram に対応し、サイトの URL も共有できます。画像の直接共有はブラウザーとサービスの対応状況によって異なり、必要に応じて画像の保存とリンクのコピーを利用できます。

固定位置のベクターパーツを組み合わせる方式で、AI によるランダム生成ではありません。参考画像のモチーフを本プロジェクトのベクター表現で描いています。顔は左下から斜めにのぞく構図で、長い髪や耳はキャンバスの外にはみ出すことがあります。

## ローカルで使う

モダンブラウザーでリポジトリの `index.html` を開くだけで利用できます。実行用の依存パッケージは不要です。

履歴は現在のブラウザーとサイトのローカルストレージに保存され、端末間では同期されません。ブラウザーデータを消去すると履歴も失われます。`file:` URL の保存動作はブラウザーによって異なるため、通常の利用には HTTPS サイトをおすすめします。UI の言語はブラウザーから自動判定し、手動でも変更できます。未対応の言語では英語を使用します。

Node.js と npm をインストールすると、オフラインでビルドできます。

```powershell
npm --offline run build
```

出力先は `dist/` です。`npm install`、環境変数、データベース、シークレットの設定は不要です。

## Cloudflare Pages へのデプロイ

### GitHub と連携する

1. このリポジトリを Fork するか、自分の GitHub リポジトリにプロジェクトを配置します。
2. Cloudflare の **Workers & Pages** で **Pages** プロジェクトを作成し、Git リポジトリのインポートから GitHub を連携します。
3. リポジトリを選び、次の設定でデプロイします。

| 設定項目 | 値 |
| --- | --- |
| 本番ブランチ | `main` |
| フレームワークプリセット | `None` |
| ルートディレクトリ | リポジトリ直下に配置した場合は空欄 |
| ビルドコマンド | `npm run build` |
| 出力ディレクトリ | `dist` |
| 環境変数 | 不要 |

デプロイ後は `*.pages.dev` のアドレスが発行され、本番ブランチへの更新の push に合わせて自動でビルドとデプロイが実行されます。[Cloudflare の静的 HTML ガイド](https://developers.cloudflare.com/pages/framework-guides/deploy-anything/)も参照してください。

### カスタムドメイン

Pages プロジェクトの **Custom domains** で所有するドメインを追加し、案内に従って DNS を設定します。本サイトのドメインは `zako.medicago.top` です。自分で公開する場合は、自分のドメインに置き換えてください。Pages にドメインを関連付けてから必要な DNS レコードを設定します。詳細は[カスタムドメインのドキュメント](https://developers.cloudflare.com/pages/configuration/custom-domains/)を参照してください。

共有先のサイト URL は `share.js` に定義されています。独自に公開する場合は、同ファイルの `https://zako.medicago.top` も変更し、共有リンクが自分のサイトを指すようにしてください。

### その他の静的ホスティング

ローカルでビルドした `dist/` の内容を静的ホスティングサービスにアップロードすることもできます。サーバープログラムは不要です。別のサービスでは、`_headers` に相当するレスポンスヘッダーを自分で設定してください。

## 開発について

| ファイル | 役割 |
| --- | --- |
| `app.js` | 選択肢、翻訳、プリセット、履歴、共通の描画と書き出し |
| `hair.js` | レイヤー構造の髪型素材 |
| `accessories.js` | 前後のレイヤーに描く髪飾りと装飾セット |
| `share.js` | 共有メニューとサイト URL |
| `site-avatar.svg` | 編集中の組み合わせとは独立したサイトアバターと favicon |
| `scripts/build.cjs` | 静的ファイルを `dist/` にコピー |

`renderAvatar` はプレビュー、素材サムネイル、履歴、書き出しに共通で使われます。素材を追加するときは、上限値、3 言語の名称、描画処理を同時に更新し、既存の履歴を維持するため ID を末尾に追加してください。`validConfig` が保存済み設定を検証し、古い履歴にない表情フィールドを補完します。猫耳・狐耳・うさ耳の顔の位置は共通で、長い耳はキャンバスの外にはみ出すことがあります。

```powershell
node scripts/check-expressions.cjs
node scripts/validate-registry.cjs
```
